Quick Tips

⚡ Formula Tricks para sa Board Exam

  • Inverting gain = negative → "Minus sign = the signal is flipped/inverted" — isipin mo binaliktad ang signal
  • "1 plus the ratio" para sa Non-Inverting → Av = 1 + Rf/Rin, palaging mas mataas sa 1
  • Voltage Follower = unity gain buffer → Gain = 1, walang resistors kailangan
  • Virtual Ground → Sa inverting amp, ang (−) input ay effectively 0V kahit hindi connected sa GND
  • Summing Amp → Bawat input may sariling resistor, lahat ay summed at inverted
  • Gain × Bandwidth = GBW → Pag mas mataas ang gain, mas mababa ang bandwidth
  • Slew Rate check: SR ≥ 2π × f × Vpeak → kung hindi, magdi-distort ang output
Golden Rules

📜 Dalawang Golden Rules ng Ideal Op-Amp

1

No Current Into Inputs

Ang input current ng ideal op-amp ay ZERO. I+ = I− = 0. Infinite input impedance — walang signal na natutunaw sa input terminals.

2

V+ = V− (Virtual Short)

Sa closed-loop configuration, ang voltage sa (+) at (−) inputs ay equal. Ito ang "virtual short circuit" concept — hindi sila literal na connected pero ang voltage ay same.

Sample Problem #1

Inverting Amplifier — Board Exam Style

PRC ECE Board Problem
An inverting op-amp has Rin = 10 kΩ and Rf = 47 kΩ. Kung ang input voltage ay 2V, ano ang output voltage?
Solusyon (Taglish):
Gamitin ang formula: Vout = −(Rf/Rin) × Vin

Vout = −(47 kΩ / 10 kΩ) × 2V
Vout = −4.7 × 2V
Vout = −9.4 V

Ang gain ay −4.7 (inverting kaya negative ang output). Tandaan: ang negative sign ay hindi mali — inverted ang signal!
✅ Answer: Vout = −9.4 V, Gain = −4.7
Sample Problem #2

Non-Inverting Amplifier

PRC ECE Board Problem
A non-inverting amplifier has R1 = 1 kΩ (Rin) at Rf = 9 kΩ. Ang input ay 0.5V sine wave. Find: (a) gain at (b) output voltage.
Solusyon:
(a) Gain = 1 + Rf/R1 = 1 + 9k/1k = 1 + 9 = 10
Paalala: "1 PLUS the ratio" — hindi tulad ng inverting na basta ratio lang.

(b) Vout = Gain × Vin = 10 × 0.5V = 5V
In-phase ang output — hindi inverted. ✓
✅ Answer: Gain = 10, Vout = 5V (in-phase)
Sample Problem #3

Summing Amplifier

PRC ECE Board Problem
A summing amplifier has Rf = 10 kΩ, R1 = R2 = 10 kΩ. Input V1 = 1V, V2 = 2V. Compute Vout.
Solusyon:
Vout = −Rf × (V1/R1 + V2/R2)
Vout = −10k × (1V/10k + 2V/10k)
Vout = −10k × (0.1 mA + 0.2 mA)
Vout = −10k × 0.3 mA
Vout = −3V

Pag equal lahat ng resistors (R1=R2=Rf), ang Vout = −(V1 + V2). Simple addition then invert!
✅ Answer: Vout = −3V (inverted sum)
Key Formulas

📐 Cheat Sheet — Lahat ng Formula

Inverting: Vout = −(Rf/Rin) × Vin
Non-Inverting: Vout = (1 + Rf/Rin) × Vin
Voltage Follower: Vout = Vin (Gain=1)
Summing: Vout = −Rf(V1/R1 + V2/R2 + ...)
Difference: Vout = (R2/R1)(V2 − V1)
Gain (dB): AdB = 20 log|Av|
Bandwidth: BW = GBW / |Av|
Slew Rate: SR = ΔVout/Δt (V/µs)
CMRR: = 20 log(Ad/Acm) dB
Memory Tricks

🧠 Op-Amp Config Mnemonics (Taglish)

"Inverted Na, Very Fast, Summed Differently"
Inverting → minus sign, binaliktad
Non-Inverting → 1 PLUS the ratio, same polarity
Voltage Follower → copycat, Gain=1
Full-wave → rectifier config
Summing → lahat ng inputs, isa-isahin
Difference → ibawas, V2 minus V1
🔴 Inverting: "MINUS = Nagbago ang direksyon"
Av = −Rf/Rin → Ang negative sign = signal is flipped.
Trick: Isipin mo, pumasok ka sa bahay (Rin), lumabas ka sa kabilang pinto (Rf) — binaliktad ka!
🟢 Non-Inverting: "ONE plus the ratio"
Av = 1 + Rf/Rin → Palaging may dagdag na 1.
Trick: "Hindi ka magiging mas maliit sa sarili mo" — gain is always ≥ 1.
🔵 Virtual Ground: "V+ = V− sa ideal op-amp"
Sa inverting amp, ang (−) input ay 0V (virtual ground) kahit hindi literal na GND.
Trick: "Pareho sila kahit magkahiwalay" — like twins na magkaiba ng tirahan pero same ugali.
⚡ Slew Rate: "SR = Bilis ng Op-Amp"
Kung mabilis ang signal change kaysa SR ng IC → Distortion mangyayari!
Check: SR ≥ 2π × f × Vpeak (dapat mas mataas ang SR para walang distortion)
📡 GBW: "Gain at Bandwidth ay kabaligtaran"
GBW = Gain × Bandwidth = constant
Kung taasan mo ang gain → bababa ang bandwidth. Trade-off ito!
Example: GBW=1MHz, Gain=10 → BW=100kHz lang

CalTech #1 — dB Gain Calculation
Find the dB gain kung ang Vout = 9.4V at Vin = 2V.
Casio Steps (fx-991ES PLUS):

1. Press MODE → 1 (COMP mode)
2. Type: 20 × log(9.4 ÷ 2) =
3. Button sequence: 2 0 × log ( 9 . 4 ÷ 2 ) =

Result: 13.44 dB

Paalala: sa fx-991EX, gamitin ang log(x) button (base-10 log). Ang log button ay nasa kaliwang bahagi ng calculator.
✅ AdB = 20 × log(4.7) = 13.44 dB
CalTech #2 — Find Rf Given Gain Spec (SOLVE mode)
Inverting amp. Gusto ng gain = −15. Kung Rin = 2 kΩ, ano ang Rf?
Manual approach (mas mabilis sa board):

Av = −Rf/Rin
−15 = −Rf / 2kΩ
Rf = 15 × 2kΩ = 30 kΩ

Casio SOLVE verification:
1. Press MODE → 5 (EQN)
2. Or use COMP: type 15 × 2 = → gets 30 instantly
3. Verify: 30 ÷ 2 = 15 ✓ (magnitude ng gain)

Trick: Sa inverting, |Av| = Rf/Rin → Rf = |Av| × Rin. Simple multiplication lang!
✅ Rf = 30 kΩ
CalTech #3 — Summing Amp via Ratio (EQN / COMP)
Summing amp: Rf=10k, R1=5k, R2=10k, V1=2V, V2=3V. Find Vout.
Casio COMP button sequence:

Vout = −Rf × (V1/R1 + V2/R2)
= −10 × (2/5 + 3/10)

Type: ( − ) 10 × ( 2 ÷ 5 + 3 ÷ 10 ) =

Inner: 2÷5 = 0.4, 3÷10 = 0.3, sum = 0.7
Outer: −10 × 0.7 = −7V

Tip: I-compute muna ang bawat fraction, tapos i-add, tapos i-multiply ng Rf.
Sa fx-991EX: pwede gamitin ang fraction button para tumpak ang computation.
✅ Vout = −7V
CalTech #4 — Non-Inverting Rf from Gain Spec
Non-inverting amp. Required gain = 11. Kung R1 = 1 kΩ, find Rf.
Formula: Av = 1 + Rf/R1

11 = 1 + Rf/1kΩ
Rf/1kΩ = 11 − 1 = 10
Rf = 10 × 1kΩ = 10 kΩ

Casio sequence:
Type: ( 11 − 1 ) × 1 =
Result: 10 (kΩ) ✓

Remember: "Bawas 1 muna bago i-multiply ng R1" — subtract 1 because the formula has +1 built in.
✅ Rf = 10 kΩ
