🔑 Must-Know Formulas
dBm = 10 log₁₀(P_mW)
Pag sinabi "reference ay 1 mW" → dBm ang gamit. 1W = +30 dBm.
dBW = 10 log₁₀(P_W)
Pag sinabi "reference ay 1 W" → dBW. 1W = 0 dBW = 30 dBm.
FSPL(dB) = 20log(d_km) + 20log(f_MHz) + 32.44
Free Space Path Loss. Doble ang distance = +6dB na loss. Doble ang frequency = +6dB.
Link Budget: P_rx = P_tx + G_tx - L_tx - FSPL - L + G_rx - L_rx
System gain/loss accounting. Positibo = gain, negatibo = loss.
dBd = dBi - 2.15
Half-wave dipole gain = 2.15 dBi. Pag sinabi "dBd" i-add 2.15 para makuha ang dBi.

📝 Sample Board Exam Problems
Problem 1: A transmitter outputs 50W. Express in dBm and dBW.
✓ 50W = 50,000 mW → 10log(50000) = 46.99 dBm ≈ 47 dBm
✓ 10log(50) = 16.99 dBW ≈ 17 dBW
Check: 47 dBm − 30 = 17 dBW ✓
Problem 2: FSPL at 900 MHz, distance = 5 km. Solve.
✓ FSPL = 20log(5) + 20log(900) + 32.44
= 13.98 + 59.08 + 32.44 = 105.5 dB
Problem 3: If signal power doubles every km, what is the gain in dB over 4 km?
✓ Doubles 4 times = ×16 power
= 10log(16) = 12.04 dB ≈ 12 dB
Shortcut: 4 × 3dB = 12 dB ✓
📚 Real ECE Board Mnemonics
Shannon Formula Trick
C = B × log₂(1 + S/N)
Mnemonic: "Channel Capacity Belongs to Log"
C = capacity (bps), B = bandwidth (Hz), S/N = signal-to-noise ratio (linear, HINDI dB!)
Board trap: I-convert muna ang SNR mula dB → linear bago i-plug sa formula!
Noise Power Mnemonic: "kTBF"
N = kTBF  (noise power)
k = Boltzmann constant (1.38×10⁻²³ J/K)
T = Temperature in Kelvin (room temp = 290 K)
B = Bandwidth in Hz
F = Noise Figure (linear)
Tandaan: "kTBF sounds like 'Katie B. Eff'" — para hindi malimutan ang order!
