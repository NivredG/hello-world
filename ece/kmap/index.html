📐 Mga Rules:
• Groups dapat powers of 2 (1, 2, 4, 8, 16, 32)
• Groups dapat rectangles — kasama ang wrap-around sa edges
• Gumawa ng pinakamalaking posibleng groups
• Bawat minterm (1-cell) dapat covered ng kahit isang group
• Don't Care cells ay pwedeng gamitin sa group pero hindi kailangang i-cover
SOP vs POS
SOP (Sum of Products) — ginagamit ang 1-cells ng K-map
Bawat group = isang product term (AND ng mga variable)
Ang lahat ng terms ay ino-OR.
Implementasyon: 2-level AND-OR logic.

POS (Product of Sums) — ginagamit ang 0-cells ng K-map
Bawat group ng 0s = isang sum term (OR ng mga variable)
Ang lahat ng terms ay ino-AND.
Implementasyon: 2-level OR-AND logic.
📚 Real ECE Board Mnemonics
RS NOR Latch — Forbidden State: "S=1,R=1 ay Bawal!"
Sa NOR-based SR latch: Q=1,Q'=1 kapag S=R=1 — invalid/forbidden state.
Mnemonic: "SR NOR: Same-Same ay BAWAL — both 1 is forbidden!"
Para sa NAND-based SR latch: S=0,R=0 ang forbidden state.
Trick: NOR → forbidden = both HIGH; NAND → forbidden = both LOW (opposite!)
FIFO vs LILO vs LIFO vs FILO — Queue/Stack Mnemonic
FIFO (First In, First Out) = Queue = pila sa palengke → first dumating, first lalabas
LIFO (Last In, First Out) = Stack = platong nakastack → last nilagay, first kukunin
LILO = shift register mode — Last In, Last Out
Trick: "FIFO = Fair! LIFO = Last tayo, so Last tayo!"
PNP vs NPN Transistor — "PNP: Pointing iN Proudly / NPN: Not Pointing iN"
NPN: Arrow sa emitter ay Nagpo-Point OUT (palabas) — current flows IN to base, OUT from collector
PNP: Arrow sa emitter ay Nagpo-Point IN — current flows OUT from base
"NPN = Never Points iN; PNP = Points iN Proudly"
Board tip: Sa NPN, conventional current flows: Collector → Emitter (sink). Sa PNP: Emitter → Collector (source).
BJT Current Ratios — "ACE, BCB, GEB"
Alpha (α) = I_C / I_E  ·  Collector over Emitter
Beta (β) = I_C / I_B  ·  Collector over Base
Gamma — I_E = I_B + I_C  ·  Emitter = Base + Collector (KCL!)
Relationship: β = α / (1 − α)   at   α = β / (β + 1)
Mnemonic: "ACE = Alpha, C over E; BCB = Beta, C over B; GEB = Gamma via E=B+C"
