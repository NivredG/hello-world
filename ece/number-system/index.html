"2's Complement: Flip, Add 1"
1. Kunin ang 1's complement (flip all bits)  →  2. Dagdag ng 1
Example: 0101 → flip → 1010 → +1 → 1011

📝 Sample PRC Board Exam Problems
Problem 1 – ECE Board Nov 2019
Convert (1A3F)₁₆ to decimal. Ano ang sagot?
Solusyon (Taglish):
Gamitin ang positional value ng hex:
1×16³ + A×16² + 3×16¹ + F×16⁰
= 1×4096 + 10×256 + 3×16 + 15×1
= 4096 + 2560 + 48 + 15
✅ Sagot: 6,719 (decimal)
💡 Tip: A=10, F=15 — alalahanin ang ABCDEF chart!
Problem 2 – CpE Board May 2022
Ang decimal na 156 ay katumbas ng anong binary number?
Solusyon (repeated division by 2):
156 ÷ 2 = 78 R 0
 78 ÷ 2 = 39 R 0
 39 ÷ 2 = 19 R 1
 19 ÷ 2 =  9 R 1
  9 ÷ 2 =  4 R 1
  4 ÷ 2 =  2 R 0
  2 ÷ 2 =  1 R 0
  1 ÷ 2 =  0 R 1
Basahin ang remainders mula IBABA pataas:
✅ Sagot: (10011100)₂
💡 Tip: Check — 128+16+8+4 = 156 ✓
Problem 3 – ECE Board Nov 2023
Hanapin ang 2's complement ng (01101001)₂ at i-express sa decimal.
Solusyon:
Original:  0 1 1 0 1 0 0 1
1's comp:  1 0 0 1 0 1 1 0 ← flip lahat
+ 1:                 + 1
2's comp:  1 0 0 1 0 1 1 1
MSB=1, kaya negative. Decimal value ng 01101001 = 105
✅ Sagot: 2's complement = 10010111 = −105 (decimal)
💡 Common mistake: Huwag kalimutang ang MSB=1 ay NEGATIVE sa signed representation!
⚠️ Common Mistakes sa Board Exam
❌
MSB Sign Bit: Sa signed binary, ang MSB (leftmost bit) = 0 kung positive, 1 kung negative. Maraming nakakalimot nito sa 2's complement problems!
❌
Octal vs Hex Confusion: Octal = digits 0-7 LANG. Pag may 8 o 9, hindi na octal! Hex = 0-9 at A-F. Alalahanin: 8 ay hindi valid sa octal.
❌
BCD ≠ Binary: BCD (Binary Coded Decimal) ay bawat decimal digit = 4 bits. Kaya 99 sa BCD = 1001 1001, HINDI 1100011!
❌
Reading remainders PABABA: Sa decimal-to-binary conversion, ang sagot ay remainders na binabasa mula sa PINAKAHULI hanggang una (bottom to top). Huwag baliktarin!
✅
Quick Check Tip: Laging i-verify ang answer mo! Binary to decimal: i-add ang positional values ng lahat ng 1-bits. Dapat tugma sa original decimal value.
⚡ Shortcut Tricks
Binary ↔ Hex (Group by 4 bits)
1010 1111 0011 = A F 3 (hex)
Hatiin ang binary sa groups ng 4 mula sa kanan, tapos i-convert each group!
Binary ↔ Octal (Group by 3 bits)
101 010 111 = 5 2 7 (octal)
Hatiin ang binary sa groups ng 3 mula sa kanan, tapos i-convert each group!
🧮 Casio fx-991ES/EX PLUS – BASE-N Mode
MODE → 4 = BASE-N
Pinaka-importante na shortcut para sa ECE/CpE board exam!
📟 Step-by-Step: Paano mag-activate ng BASE-N
1.Pindutin ang MODE→ Menu lalabas
2.Pindutin ang 4→ BASE-N mode
3.Default base: DEC (Decimal)
4.Para mag-switch ng base: DEC / HEX / BIN / OCT buttons
Ready na mag-convert!
🔑 Key Buttons sa BASE-N Mode
DEC button
Pindutin para pumunta sa Decimal mode. Keyboard shortcut sa Casio: ALPHA + 9
HEX button
Hexadecimal mode. A–F keys maa-access via ALPHA
BIN button
Binary mode. Digits 0–1 lang ang gagana.
OCT button
Octal mode. Digits 0–7 lang ang gagana.
⚙️ Logical Operations sa BASE-N Mode
ANDBitwise AND — ALPHA + AND key
ORBitwise OR — ALPHA + OR key
XORExclusive OR — ALPHA + XOR key
NOTBitwise NOT (1's comp) — ALPHA + NOT key
XNORXNOR — ALPHA + XNOR key
💡 Sa fx-991EX: Ilang operations ay nasa CATALOG (SHIFT + 4)

CalTech Example 2 – Bitwise AND Operation
Compute: 1010 AND 1100 (binary). Gamitin ang Casio.
Exact Button Presses:
MODE → 4 (BASE-N mode)
BIN (binary mode)
Type: 1 0 1 0
ALPHA + AND
Type: 1 1 0 0

✅ Result: 1000 (binary) = 8 (decimal)
Manual verification: 1010 AND 1100 → bit-by-bit: 1·1=1, 0·1=0, 1·0=0, 0·0=0 → 1000 ✓

"Octal = Walang 8 at 9!"
Pag nakakita ka ng 8 o 9 sa isang number na tinatawag na octal — MALI YAN!
Octal digits: 0 1 2 3 4 5 6 7 — hanggang 7 lang!
Speed Trick: ×2 at ÷2
Sa binary, ang shift left (add 0 sa kanan) = multiply by 2.
Ang shift right (tanggalin ang rightmost) = divide by 2.
Example: 0101 (5) → shift left → 1010 (10) ✓

Number System Quick ID Trick
Pag may 8 o 9 → HINDI octal (max digit sa octal ay 7)
Pag may A, B, C, D, E, F → Hexadecimal (guaranteed)
Pag lahat 0 at 1 lang → pwedeng Binary
Pag lahat 0–7 lang → pwedeng Octal o Binary
Mnemonic: "Pag may letter = Hex, pag may 8/9 = Di-Octal!"
