# PinasTools.com - Flagship Build Rules

## MANDATORY for every tool:
- Single HTML <100KB (all inline, no CDN)
- Design: bg #111318, gold #f59e0b, font Outfit, mobile-first, rounded 16px
- Language installer modal FIRST OPEN:
  Title: PinasTools Installer - Select Language
  Options: Tagalog (Default), English, Cebuano, Ilocano
  Save: localStorage pinastools_lang, skip next time
- Content: Taglish, board tips, Bataan refs
- Tabs: Calculator | Table | Board Tips
- Save DIRECT to ./ece/[slug]/index.html, create folder
- Offline ready, GCash ready

Examples: pec-wire-size, db-converter, resistor
Quality = flagship gold standard.
