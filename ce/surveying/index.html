CE Board Exam — Surveying Tips (Taglish)

Top 1: Palaging i-check ang quadrant ng bearing

Ang pinakacommon na mali sa board exam ay maling sign ng Latitude o Departure. Tandaan:

  • NE quadrant: Lat = +, Dep = + (Norte-Este = positive lahat)
  • SE quadrant: Lat = -, Dep = + (Sur-Este)
  • SW quadrant: Lat = -, Dep = - (Sur-Oeste = negative lahat)
  • NW quadrant: Lat = +, Dep = - (Norte-Oeste)

Top 2: Traverse Sample Problem (Bataan context)

Isang survey sa Balanga City, Bataan — 4 legs:

Leg 1: N 45°30' E, d = 120.50 m Lat = 120.50 × cos(45.5°) = +84.62 m Dep = 120.50 × sin(45.5°) = +86.12 m Leg 2: S 30°00' E, d = 95.20 m Lat = 95.20 × cos(30°) = -82.43 m Dep = 95.20 × sin(30°) = +47.60 m Leg 3: S 60°15' W, d = 110.30 m Lat = 110.30 × cos(60.25°) = -54.77 m Dep = 110.30 × sin(60.25°) = -95.93 m Leg 4: N 15°45' W, d = 88.40 m Lat = 88.40 × cos(15.75°) = +85.06 m Dep = 88.40 × sin(15.75°) = -24.01 m ΣLat = 84.62 - 82.43 - 54.77 + 85.06 = +32.48 ← may error! ΣDep = 86.12 + 47.60 - 95.93 - 24.01 = +13.78 ← may error! Misclosure = √(32.48² + 13.78²) = 35.29 m Perimeter = 120.50 + 95.20 + 110.30 + 88.40 = 414.40 m Precision = 1 : (414.40/35.29) ≈ 1:12 ← very poor (needs recheck)

Sa board exam, ang tamang answer ay usually 1:5000 to 1:20000. Kung mali ang sign, lalabas very poor na precision.

Top 3: DMD Method para sa Area

  • DMD ng FIRST leg = Departure ng first leg
  • DMD ng nth leg = DMD(n-1) + Dep(n-1) + Dep(n)
  • DMD ng LAST leg = - Departure ng last leg (dapat equal, otherwise may misclosure)
  • Double Area = Σ(Adjusted Lat × DMD)
  • Area = |Double Area| / 2
  • I-check: DMD ng last leg dapat ito equals -(Dep ng last leg)

Top 4: Simple Curve — Kailan gagamitin ang alin

  • Tangent T — distance from PC/PT to PI (intersection point). Ginagamit para malaman kung nasaan ang PC at PT sa centerline.
  • External E — distance from PI to midpoint ng curve. Ginagamit sa sight distance checks.
  • Middle Ordinate M — clearance from chord to curve midpoint. Kapareho ng clearing requirements.
  • Chord C — straight line from PC to PT. Ginagamit sa stakeout kung walang enough setup.

Top 5: Differential Leveling — Mga maling praktikal

  • BS palagi sa naunang turning point (yung natiknan na). FS sa susunod na TP.
  • HI = Elevation ng instrument station + BS reading
  • Elevation ng FS station = HI - FS
  • Check: ΣBS - ΣFS = Elevation(last) - Elevation(first)
  • Allowable error = m√K ; m = 12mm para sa 3rd order; K = distance in km
  • Intermediate sights (IS) ay hindi kasali sa check computation!

Top 6: Philippine Land Registration Authority (LRA) Context

  • Lahat ng cadastral surveys sa Pilipinas ay ginagawa under DENR-LMB at NAMRIA
  • Original Certificate of Title (OCT) — unang registration ng lupa
  • Transfer Certificate of Title (TCT) — kapag nalipat na sa ibang tao
  • Ang geodetic engineers (GE) ang may authority mag-sign ng survey plans
  • PRS92 ang opisyal na datum ng lahat ng cadastral surveys ngayon (RA 10176)
  • Metes and bounds description — bearing at distance ang ginagamit, hindi GPS coordinates lang
  • Lotplan (Lot Plan) at Vicinity Map — required sa lahat ng land titling application

Top 7: Board Exam Time Management

  • Traverse problems: ~8-12 minutes kada buong computation. Use Casio REC( ) function.
  • Simple curve: ~3-5 minutes lang kung memorized ang formulas. TEMC mnemonic.
  • Leveling: ~5-8 minutes. Gawin table agad, huwag mag-mental math.
  • Magsimula sa pinakamadaling items. Huwag maiipit sa isang mahirap na problem.
  • Always check units — km vs m, degrees vs radians.
Taglish Mnemonics para sa Board Exam
TEMC
Para sa Simple Horizontal Curve elements:
Tangent length → External distance → Middle ordinate → Chord

Tandaan: "TEMC sounds like 'TEMAK' — ang curve elements na hindi mo dapat makalimutan sa board!"
T = R·tan(I/2) ← Tangent E = R·(1/cos(I/2) - 1) ← External M = R·(1 - cos(I/2)) ← Middle ordinate C = 2R·sin(I/2) ← Long Chord Lc = πRI/180 ← Curve length
BLND
Para sa Bearing reading order:
Bearing: Look at N or S first → Number of degrees → then Direction (E or W)

"N 45°30' E" — Norte, 45 degrees 30 minutes, Este.
"BLND — Bisita Lagi Nang Determinado" para hindi ka malito sa bearing vs azimuth!
Norte-Este = PLUS
Sign rules para sa Latitude at Departure:
Norte (+Lat) at Este (+Dep) = Positive
Sur (-Lat) at Oeste (-Dep) = Negative

"NE = dagdag, SW = bawas — simple lang!"
SE = Lat(-) Dep(+) | NW = Lat(+) Dep(-)
CLONE
Para sa precision ratio ng traverse:
Closure = Linear misclosure Over Net distance = Error ratio

Precision = 1 : (Perimeter / Linear Misclosure)
"CLONE ng perfect closure = 1:infinity!"
DMD — "Dalawang Meridian Distance"
Para sa DMD area computation:
1. First DMD = First adjusted departure
2. DMD(n) = DMD(n-1) + Dep(n-1) + Dep(n)
3. Last DMD dapat equal sa last departure (baligtad na sign) — kung hindi, may mali!
4. Double Area = Σ(Adjusted Lat × DMD)
5. Area = |Double Area| / 2

"Dalawang beses palakihin ang distansya, hatiin sa dalawa — simple!"
Casio fx-991ES PLUS CalTech Techniques
1 REC( ) para sa Lat at Dep — ang pinaka-importanteng technique!

Ang REC(r, θ) function ay nagco-convert ng polar to rectangular.
Para sa surveying: REC(distance, bearing_angle)

Keypress: SHIFT → 2 → 3 (or yung REC button)

Halimbawa: N 45°30' E, d = 120.50 m
Press: REC(120.50, 45.5) → ENTER
Result X = Departure = 86.12 (Este = positive)
Press SHIFT → ENG para makita Y = Latitude = 84.62

Para sa S 30° E: bearing angle = 30°, pero kailangan mong manually lagyan ng sign: Lat = -result, Dep = +result

2 POL( ) para sa distance at bearing — reverse computation

Kapag may Lat at Dep, gamitin ang POL(x, y) para makuha ang distance at angle.
Keypress: SHIFT → 2 → 2 (POL)

POL(Departure, Latitude)
Result r = Distance | Result θ = bearing angle

Halimbawa: POL(86.12, 84.62) → r = 120.50 m, θ = 45.5°
"P para sa POL, para sa Pabalik na computation!"

3 Memory A-F para sa multiple traverse points

Mag-store ng intermediate results para hindi ka na mag-recompute.
Store: Press SHIFT → RCL → (A/B/C/D/E/F)
Recall: Press ALPHA → (A/B/C/D/E/F)

Strategy para sa traverse:
A = ΣLat running total
B = ΣDep running total
C = Perimeter running total

After each leg: compute lat, add to A; compute dep, add to B; add distance to C.

4 STAT Mode para sa sums ng maraming values

Pinaka-mabilis na paraan para makuha ang ΣLat at ΣDep ng maraming legs:
1. Press MODE → 3 (STAT) → 1 (1-VAR)
2. I-enter ang bawat latitude value (maging maingat sa signs)
3. Press SHIFT → 1 → 4 → 1 para makita ang Σx (sum)

Gawin nang dalawang beses — isa para sa latitudes, isa para sa departures.
"STAT = Swabe na Totaling para sa Abot-kayang Traverse!"

5 TABLE Mode para i-list ang lahat ng Lat values

Para sa mga gusto mag-compute ng lahat ng cos at sin ng multiple bearings:
1. Press MODE → 7 (TABLE)
2. Enter function: f(X) = D cos(X) (D = distance, X = bearing)
3. Start: unang bearing, End: huling bearing, Step: increment

Best para kapag uniform ang distances o gusto mong i-check multiple values.
"TABLE mode = Tamang-tama para sa Abot-kayang List ng Latitudes!"

GEAS & Real Board Mnemonics — General Knowledge
Planets: "Mang Victor Espinosa Mag Jogging Sa Umaga Nang Pumayat"
Mercury · Venus · Earth · Mars · Jupiter · Saturn · Uranus · Neptune · Pluto
Kahit na officially "dwarf planet" na si Pluto, laging kasama pa rin ito sa board exam questions. I-memorize ang order mula sa Araw papalabas.
Atmosphere Layers: "The Strong Man's Triceps Explode"
Troposphere · Stratosphere · Mesosphere · Thermosphere · Exosphere
Mula sa ibabaw ng lupa paataas. Ang troposphere (0–12 km) ang layer ng lahat ng weather. Ang ozone layer ay nasa stratosphere. Relevant sa atmospheric pressure problems sa fluid mechanics.
Compass Directions: "Never Eat Slimy Worms"
North · East · South · West — clockwise order
Direktang applicable sa surveying at traverse problems. Ang bearing notation sa Pilipinas: N θ° E, S θ° W, etc.
Navigation: "Can Dead Men Vote Twice"
Compass + Deviation = Magnetic + Variation = True
Para sa nautical/aviation navigation at geodetic surveying. Ang magnetic declination (variation) sa Pilipinas ay humigit-kumulang 0°–3° East ngayon. Ang compass bearing + declination = true north bearing.
Compass ± Deviation = Magnetic ± Variation = True (Geographic North)
"East is Least, West is Best"
Para sa magnetic variation correction:
Kung ang declination ay East → subtract mula sa magnetic para makuha ang true (East is Least)
Kung ang declination ay West → add sa magnetic para makuha ang true (West is Best)
Mnemonic para sa GEAS navigation at geodetic engineering problems sa board exam.
